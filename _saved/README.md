# Saved for later

Work that is finished but not live yet. GitHub Pages builds this site with
Jekyll, which does not publish folders whose names start with `_`, so
nothing here is reachable on the website.

- **`applicant_form.html`** - the online rental application (the applicant
  page as it was until 2026-09-29): name, email, phone, move-in date, text
  consent, property of interest, up to 10 roommates, and a message, posted
  to `POST /api/applications`. The applicant page shows "Coming soon" for
  now, at the user's request. To bring the form back, move this file back
  to `applicant/index.html` (its links are written for that folder). The
  last commit with it live is `e81c562`.
